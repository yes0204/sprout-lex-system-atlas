코드 구현

일반 경로와 원문 정책

API는 일반 그래프로 전달합니다. 공개 원문 모드는 매니페스트·조문별 허용 여부를 확인하고 미허용 근거를 제외합니다.

공개 모드에서는 사전 기반 용어 되묻기와 외부 관계 끝 표시가 비활성입니다. 이 스위치는 실행 서버 설정을 변경하지 않습니다.

CI·로그 전용 해설

전용 API 분기·활성화 설정·전용 원문 endpoint를 삭제했습니다. 과거 실험 모듈과 자료는 증적용으로 보존됩니다.
